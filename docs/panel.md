# 面板账号管理

## 登录任务

登录任务只从“已保存账号”中选择。调试和登录按钮与页面标题、说明文字位于同一行，下面直接显示账号列表和代理池；日志紧跟代理池。左侧账号框不短于右侧代理池、日志的整体高度，列表内容超出后滚动。小屏幕会恢复为单列布局。

账号选择框和“账号记录”页使用同一排序规则：严格符合自动更新时间 `YYYY-MM-DD HH:mm` 的记录按时间从早到晚排列；空时间、示例值 `1` 或其他手动文本排在最前。同一类记录保持原有相对顺序。

## 添加记录

账号记录的时间可以留空。此时 backend 使用 `Asia/Singapore` 时区生成当前添加时间，保存格式为 `YYYY-MM-DD HH:mm`；手动输入的内容仍按原样保存，因此不符合该格式的内容会按未排序时间处理。
