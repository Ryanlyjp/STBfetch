# 面板账号管理

## 登录任务

登录任务只从“已保存账号”中选择。调试和登录按钮与页面标题、说明文字位于同一行，下面直接显示账号列表和代理池；日志紧跟代理池。左侧账号框不短于右侧代理池、日志的整体高度，列表内容超出后滚动。小屏幕会恢复为单列布局。

“WAF 识别失败时重试一次”默认关闭。开启后，只有第一次完整 Camoufox 会话以 `AWS WAF视觉识别` 失败时，系统才会在该会话结束后创建一次新的会话重新执行；第二次失败、Turnstile 失败、登录失败和代码采集失败都不会继续重试。

每个账号的完整同页 Camoufox 流程由 backend 最多等待 180 秒，包含 Turnstile、登录和优惠码采集；超过该总时限即记为本次账号失败。

账号选择框和“账号记录”页使用同一排序规则：严格符合自动更新时间 `YYYY-MM-DD HH:mm` 的记录按时间从早到晚排列；空时间、示例值 `1` 或其他手动文本排在最前。同一类记录保持原有相对顺序。

## 添加记录

账号记录的时间可以留空。此时 backend 使用 `Asia/Singapore` 时区生成当前添加时间，保存格式为 `YYYY-MM-DD HH:mm`；手动输入的内容仍按原样保存，因此不符合该格式的内容会按未排序时间处理。

账号密码也可以留空，但必须先在“面板设置”中设置默认账号密码。留空提交时，backend 会把当时的默认密码写入这条账号记录；以后修改默认密码不会改动已经保存的账号。未设置默认密码时，空密码提交会返回明确的校验错误。

账号记录表单不会使用浏览器保存的登录凭据：字段关闭自动填充，并标记为常见密码管理器应忽略的非登录字段。密码保持遮蔽输入；第三方扩展可以选择无视网页标识，此时需在扩展中对本机面板关闭该站点的自动填充或保存提示。

## 优惠码库

每次任务完整取得四组优惠码后都会新增一条归档。即使同一账号之后再次成功，旧归档也会保留，不按账号覆盖。

桌面端每行显示两条摘要，每页 20 行、共 40 条；手机端保持单列，每页 20 条。点击摘要后，优惠码和下次时间在该组下方占满整行，连接标记会指向触发展开的左侧或右侧记录。

每条归档可单独勾选。“全选本页”只改变当前页的勾选状态，切换页面后已经勾选的其他页记录仍保留，选中总数会持续显示；“删除”会在确认后一次删除所有已选记录。

## 默认账号密码

“面板设置”可以设置或替换默认账号密码。前端只读取“是否已经设置”的状态，接口不会返回密码内容；默认密码与账号记录、优惠码库一起保存在 `data/secure_store.json` 的加密载荷中。修改面板密码时，这三类数据会一起重新加密。
